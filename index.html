Week 1

Print & Input

Make the computer show output with print(), and ask the user questions with input().

print()stringsinput()reading errors

Reference

print() displays output

print("Hello, world!")

Shows: Hello, world! Each print() shows up on its own line.

Strings are text in quotes

"pizza"
"I love coding!"
"( ^_^ )"

Quotes always come in pairs: one to start, one to end.

input() asks a question

name = input("What is your name? ")
print("Hi " + name)

The program waits for the user to type and press Enter. Leave a space at the end of your question.

+ joins strings

print("My name is " + "Maya")

Shows: My name is Maya. Forget the space and you get “My name isMaya”.

Common bugs

Print("hi")

NameError. Use a lowercase p.

print("hi)

SyntaxError. Close the quote.

print("hi"

SyntaxError. Close the parenthesis.

print(hi)

NameError. Text needs quotes.

Week 2

    
Variables

    
A variable stores a value so your program can remember it and use it later.

    
variablesvaluesname vs "name"naming rules

  


  

    
Reference

    

      

        
A variable stores a value

        

          
name"Maya"

          
name = "Maya"
print(name)

        

        
Variable name on the left, value on the right. Read = as “stores”.

      

      

        
Quotes change everything

        
name = "Maya"
print(name)      # Maya
print("name")    # name

        
No quotes: use what’s in the box. Quotes: print the exact text.

      

      

        
A new value replaces the old one

        
food = "pizza"
food = "tacos"
print(food)      # tacos

        
A variable holds one value at a time: the newest one.

      

      

        
Naming rules

        
    
          
  • No spaces: use my_name
    • 
          
  • Can’t start with a number
    • 
          
  • Capitals matter: Name and name are different
    • 
          
  • Pick names that describe the value
    • 
        

      

    

  


  

    
Common bugs

    

      
my name = "Ava"
SyntaxError. No spaces in names: my_name.

      
name = Maya
NameError. The value needs quotes.

      
print(Name)
NameError. Capitals must match exactly.

Week 3

    
Data Types

    
Every value has a type. The type decides what you can do with it, like math or joining text.

    
strings, integers, floatsmath operatorsint()str()

  


  

    
Reference

    

      
String
"hello"  "42"
Text in quotes, even if it looks like a number.

      
Integer
12  500  -3
A whole number. No quotes.

      
Float
3.5  9.99
A number with a decimal point.

    

    

      

        
Math operators

        
print(5 + 3)    # 8   add
print(9 - 4)    # 5   subtract
print(6 * 7)    # 42  multiply
print(7 / 2)    # 3.5 divide

        
Multiply is a star *, not an x.

      

      

        
Same +, different jobs

        
print("5" + "5")  # 55
print(5 + 5)      # 10

        
Strings get glued together. Integers get added.

      

      

        
input() always gives a string

        
age = int(input("Age? "))
print(age + 1)

        
int() turns the typed text into a number so you can do math.

      

      

        
str() for sentences

        
print("You are " + str(age))

        
str() turns a number back into text so + can join it to a sentence.

      

    

  


  

    
Common bugs

    

      
print("Age: " + 12)
TypeError. Use str(12) to join a number.

      
int("twelve")
ValueError. int() needs digits like 12.

      
int(input("Age? ")
SyntaxError. Two ( need two ) at the end.

Week 4

    
If / Elif / Else

    
Teach your program to make decisions. First, meet booleans: values that can only be True or False.

    
booleanscomparisonsif / elseelifindenting

  


  

    
Part 1: Booleans

    

      

        
A boolean is True or False

        
TrueFalse

        
is_raining = True
has_homework = False

        
A new data type with only two values. No quotes, and always a capital T or F.

      

      

        
Comparisons give a boolean

        
print(5 > 3)          # True
print(10 == 2)        # False
print("cat" == "cat")  # True

        
Python checks the comparison and answers True or False.

      

      

        
Comparison operators

        

          
== equal to

          
!= not equal to

          
> greater than

          
< less than

          
>= greater or equal

          
<= less or equal

        

        
= stores a value. == asks “are these equal?”

      

    

  


  

    
Part 2: Making decisions

    

      

        
if runs code when it’s True

        
answer = input("Like pizza? ")
if answer == "yes":
    print("Same!")

        
If the condition is True, the indented code runs. If it’s False, Python skips it.

      

      

        
else is the backup plan

        
if answer == "yes":
    print("Same!")
else:
    print("More for me!")

        
else runs when the if is False. One of the two always runs.

      

      

        
elif adds more choices

        
if score >= 90:
    print("Amazing!")
elif score >= 70:
    print("Nice job!")
else:
    print("Keep practicing!")

        
Python checks from top to bottom and runs only the first one that’s True.

      

      

        
The two rules

        
    
          
  • End the if, elif or else line with a colon :
    • 
          
  • Indent the code inside with 4 spaces (or the Tab key)
    • 
          
  • Only indented lines belong to the if
    • 
        

      

    

  


  

    
Common bugs

    

      
if age = 12:
SyntaxError. Use == to compare.

      
if answer == "yes"
SyntaxError. Add a colon at the end.

      
print("Same!")
IndentationError when not indented under the if.

      
is_fun = true
NameError. Booleans need a capital: True.

      
if input("Age? ") > 12:
TypeError. Use int() before comparing numbers.

      
"Yes" == "yes"
Sneaky bug: this is False. Capitals matter!
